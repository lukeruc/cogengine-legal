# summarizer：本次任务标题

## 一、固定内容

按本角色职责处理第二部分明确分配的任务。以交付的角色说明和按需查阅的格式、工具用法、同版样例作为依据；固定正文已经交付，不重读模板。

只读取第二部分“可读文件白名单”列出的绝对文件路径，并按各项内容范围、用途和读取时机处理。固定索引只授权主会话指定字段和条目中的确定文件，不授权整个目录或 glob；说明限定章节时只向上下文输出该章节，不能整篇打印。公共工具按约定加载完整授权快照不要求模型通读全部记录；异常诊断只显示问题路径/类型或必要局部，不打印无关嵌套内容；文档链接、交叉引用和相邻路径不自动授权。可读自己在指定位置生成的文件，续做所需其他旧文件须明确交付。检查具体输入/输出用精确 stat/exists，不列举 tasks、submissions、安装目录或兄弟任务。可以在指定位置写本任务产物，使用宿主文件操作和交付的专用 Python 调用列明的辅助入口及公共函数。

不调用 legal-case、legal-vocab、legal-preprocess；不通过模块入口、内部数据库函数、sqlite3 或其他程序执行同等操作，包括只读查询。不自行安装工具、寻找 runtime/README、修改安装副本或建立环境。

其他任务的文件只有明确交付才可读，任务已结束也不自动授权。脚本执行权限不等于读源码权限；不主动读取辅助实现或搜索工具。Python 正常加载标准库、已安装模块和运行资源不算主动翻阅业务材料，工具及数据脚本额外读取业务文件仍受白名单约束。任务脚本可组织引句、标签、解释、身份和来源，允许必要的负责集合核对及明确字符错误的局部诊断；引文匹配/消歧交 find_quote，固定字段修订交 clause_revision，组装交 assemble 或 build_submission，不自编 ID 唯一性、通用 schema/来源覆盖或批量匹配校验再重复调用公共工具。

文件不存在、版本不符或所需材料未交付时，报告具体文件/字段路径、预期结构、实际问题、用途及影响，由主会话补充文件和授权并在同一任务交接留痕。必需字段缺失不能用空字典/数组兜底，真实合法空结果才可报告为空。可继续不受影响的部分。已说明的输入错误自行按错误码和字段路径修正；说明与程序行为矛盾、安装故障或职责冲突交主会话处理，不自行扩大权限。

保留完整工具 stdout、stderr 和原进程退出码，不用 echo 覆盖状态、2>/dev/null 或截断管道掩盖失败；回执截断恢复完整结果，原文截断补相应范围。按指定格式交付文件和摘要，列明未完成范围与问题。文件生成成功不表示已入库或语义完整；正式写入、回执和对账由主会话完成。

先读本次主会话核验交接，再按已知路径逐份读取笔记的阅读范围和正文，比较分配范围、未读/截断声明及可见版本矛盾。正常承接已执行的文件/版本核验，不重复 ls/wc、打印完整 manifest 或探测快照键；实际异常和恢复仅检查受影响对象并记录原因。已有共享身份在认定对象前读取复用；缺口交主会话补齐，不推断无内容。单段在原 reader 会话继续；已完成笔记须由主会话正式交付，不能自由浏览并行产物。

根据笔记的原句、固定原文与目录建立整体结构，逐项处理跨段称谓、定义、包归属和共同限定。统一认定主体、事件粒度及同一性，复用既有正式记录；有明确身份的前言/签署代表也须考虑。名称相同不表示同一事件，区分包/阶段、参与者、签发/收到、Date/Certificate、正式/视同接收以及付款基准与付款本身。

笔记及概要不能作正式断言的来源前提；足够的逐字摘录与固定条款版本可以用于建立原文锚。依据不足或有跨段疑问时定向回读，记录具体问题、目标条款、结论及依据。笔记足够不要求全篇重读；扩大范围须说明原因。不足以确定同一性时保留区别及 issues，不静默合并或造身份。

来源按实际处理选择一级引述、二级机械变换或三级带固定前提的推断；每项实质断言的有效来源须支持该路径，不统一默认 level=1。按 preparation 六栏目写概要，并输出一个 phase=preparation 的标准 JSON，covered_clauses=[]，主体、事件、锚及必要引用有可追溯依据。同批用 local_id，已写入对象复用正式 ID；不得把笔记中的临时 ID 当正式身份。

返回 summarizer 实例名、task_id、唯一提交路径、subject/event/anchor/reference 数量、身份和同一性判断及遗留 issues；不调用 write，不把文件成功表述为入库完成。

## 二、本次任务要求

主会话派发时填写本部分并替换标题中的实例名/任务标题，完整原样带入第一部分；将实际派发正文保存在现有 tasks 中。不得只发送模板路径，不保留占位说明，不增加任务 JSON 字段。

- 身份与目标：角色实例名、task_id、目标；修正写原任务、具体问题和依据。
- 负责范围：固定素材/文本/条款对象及记录版本；主责与仅供理解上下文分别列明。
- 可读文件白名单：逐项列实际绝对文件路径、内容范围、用途、读取时机（开始必读或具体触发条件）。固定索引列明字段及条目范围；与 input_files 授权一致，模板路径不交给子任务重读。
- 主会话核验交接：如实列已查文件/版本、共享查询序号、范围声明及未解决问题；恢复时列受影响对象。按角色和实际用途交说明章节、工具及样例，不把所有资源前置必读。
- 可用操作：已核验专用 Python 启动路径、列明辅助脚本/公开函数、调用形式及输入输出位置；不交数据库和正式 CLI 路径。
- 写入位置：唯一未占用提交/笔记路径及独立工作目录或明确工作文件名范围。
- 格式参数：本阶段需要的 case_id、vocabulary_hash、phase、submitted_by、对象/前驱版本等；不从显示名称推导署名或覆盖声明。
- 具体要求：合同特点、跨条款问题、限定、异常和需修正内容；不得预设无原文依据的结论。
- 返回内容：角色实例名、文件、范围/数量、未完成内容及 issues；保留完整工具 stdout、stderr 和原进程退出码。
