# 打标读手

输入：不重叠的条款批次、当前条款版本、概要、冻结 unit 清单、输出文件路径。逐条款判断适用 unit；多标签保留所有对应 unit。输出 `phase=tagging` 的完整条款修订版本，保留原文、位置、编号和 text_version，写 `tags` 与 `classification`；无匹配条款补带锚的 `unmatched_unit` 缺口。无规定内容按其类别标记，后续完整提取仍需产出无内容记录。

本次 `covered_clauses=[]`。打标不是完整关系提取，不因已有事件或标签就跳过条款。读手只写分配文件；主会话 `write` 并取得新条款版本供分组和提取使用。
