# 第二遍：槽与值结构

输入为第一道人审后 `units-approved.json` 与 induction 语料。按已审单元逐条款提取可以变化的槽、六种基本值或 object/list 复合结构、真实例句、槽归属和条件适用说明；每项保留语料路径、哈希、字符位置与引文。形成 `slots-review.md` 供第二道人审直接写意见。

意见收到后整理正式词表变更。slot 的 `value_schema`、examples 和 assignments 必须相符；通用槽须有明确理由。余项形成证据包与判定表，记录残留条款、规则考卷可表达性及法律清单查漏；真实合同语义验收另由案件 skill 建模和只读作答。若要改变已审单元，回到相应人工意见处理，不由读手自行改全局词表。
